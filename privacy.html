מדיניות פרטיות

עודכן לאחרונה: 10 באוגוסט 2026

1. מי אנחנו

Veltrum / וולטרום ("אנחנו") פועלת בישראל כעוסק פטור, תיק מס' 331644872, ומספקת שירותי אוטומציה לעסקים: סוכני WhatsApp לתיאום תורים ושירות לקוחות, מנועי הצעות מחיר אוטומטיים וכלים פנימיים. מדיניות זו מסבירה איזה מידע אנחנו מעבדים במסגרת האתר והשירותים, למה, ואיך אנחנו שומרים עליו.

2. איזה מידע אנחנו מעבדים

  • פרטי קשר שאתם מוסרים לנו ישירות: שם, מספר טלפון, אימייל.
  • תוכן הודעות שנשלחות לסוכני ה-WhatsApp שאנחנו מפעילים עבור עסקים — כולל טקסט, תמונות וקבצים.
  • פרטי תיאומים: מועדי תורים, סוג השירות המבוקש, הערות שנמסרו במהלך השיחה.
  • מידע עסקי שלקוחותינו העסקיים מחברים למערכת: יומנים, רשומות CRM, מחירונים ומסמכים.

3. עיבוד הודעות דרך WhatsApp Cloud API של Meta

סוכני ה-WhatsApp שלנו פועלים על גבי WhatsApp Cloud API — הממשק הרשמי של Meta לעסקים. המשמעות: הודעות שאתם שולחים למספר העסקי עוברות דרך השרתים של Meta, בהתאם לתנאי השירות ולמדיניות הפרטיות של Meta, ומגיעות אלינו לצורך מתן השירות — תיאום תור, הכנת הצעת מחיר או מענה לפנייה.

אנחנו מעבדים את תוכן ההודעות אך ורק לצורך הפעלת השירות עבור העסק שאליו פניתם. איננו מוכרים את המידע ואיננו עושים בו שימוש למטרות פרסום.

4. איך המידע נשמר ולכמה זמן

המידע נשמר במערכות מאובטחות עם הרשאות גישה מצומצמות. תוכן שיחות נשמר רק כל עוד הוא נדרש למתן השירות, לתיעוד עסקי סביר או לעמידה בדרישות הדין, ולאחר מכן נמחק. אפשר לבקש מחיקה מוקדמת בכל שלב — ראו סעיף "הזכויות שלכם".

5. למה משמש המידע

  • מתן השירות ותפעולו השוטף: תיאום תורים, הצעות מחיר, מענה ללקוחות.
  • שיפור הדיוק והאיכות של הסוכנים והתהליכים שאנחנו מפעילים.
  • חזרה אליכם לגבי פנייה שהשארתם.
  • עמידה בדרישות הדין.

6. שיתוף מידע עם צדדים שלישיים

אנחנו משתפים מידע רק כשהדבר נדרש להפעלת השירות:

  • Meta — כמפעילת WhatsApp Cloud API שדרכה עוברות ההודעות.
  • ספקי אחסון וענן שמארחים את המערכות שלנו.
  • מערכות יומן ו-CRM שהעסק הרלוונטי חיבר לשירות.
  • רשויות מוסמכות, אם הדין מחייב זאת.

כל ספק כזה כפוף לחובות סודיות ואבטחת מידע.

7. הזכויות שלכם

בהתאם לחוק הגנת הפרטיות, התשמ"א-1981, ולתקנות שהותקנו מכוחו, יש לכם זכות לעיין במידע שנשמר עליכם, לבקש תיקון של מידע שגוי, לבקש מחיקה, ולקבל עותק של המידע (ייצוא). כדי לממש כל אחת מהזכויות — פנו אלינו באחד מפרטי הקשר שבסעיף 10, ונטפל בפנייה תוך זמן סביר ולא יאוחר מהקבוע בדין.

8. אבטחת מידע

אנחנו מיישמים אמצעי הגנה בהתאם לתקנות הגנת הפרטיות (אבטחת מידע), התשע"ז-2017, ובהם הצפנת תעבורה, הרשאות גישה מצומצמות לפי תפקיד וגיבויים מנוהלים. אף מערכת אינה חסינה לחלוטין, אך אנחנו פועלים לצמצם סיכונים באופן שוטף.
